# Fantasy HQ — deild 1730773

Sjálfstæð Fantasy Premier League-vefsíða fyrir classic league **1730773**.

## Innihald

- Lifandi deildartafla úr opinbera FPL API.
- Vikuskítkast og vikuleg greining.
- Hetja og Skíta vikunnar.
- Rivalry Center.
- Transfer Hall of Shame.
- Fantasy Wrapped fyrir hvern stjórnanda.
- Power Rankings byggð á nýlegu formi.

## Uppsetning

Verkefnið er statísk vefsíða með Vercel serverless proxy:

- `index.html` — framendi og greining.
- `api/fpl.js` — proxy fyrir opinbera FPL API.
- `vercel.json` — Vercel stillingar.

## Vercel

Framework preset: **Other**

Root directory: `.`

Engin tenging er við Nova Fantasy HQ eftir að verkefnið var afritað. Upprunalega branchið er aðeins grunnur að þessu sjálfstæða repository.
